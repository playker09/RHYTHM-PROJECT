메뉴 배경 음악 폴더

아래 이름으로 파일을 넣으면 자동으로 반복 재생된다. 파일이 없으면 그 화면은 조용하다.
형식은 mp3 / ogg / wav 중 하나 (같은 이름이 여러 개면 mp3 우선).

  menu.mp3    타이틀 + 메인 메뉴 (두 화면에서 끊기지 않고 이어진다)
  select.mp3  선곡 화면. 고른 곡의 미리듣기가 안 나올 때만 나온다
  result.mp3  결과 화면 (등급 효과음 뒤에 시작)

곡별 BPM 과 음량은 이 폴더에 bgm.json 을 만들어 적는다 (둘 다 생략 가능).

  {
    "menu":   {"bpm": 120, "volume": 0.8},
    "select": {"bpm": 96},
    "result": 90
  }

  bpm     배경 무대가 이 박자로 움직인다. 적지 않으면 120. 숫자만 쓰면 BPM 으로 읽는다.
  volume  기본 음량에 곱하는 배수. 1.0 = 기본, 0.5 = 절반, 0 = 끔, 최대 2.5.
          설정 화면의 전체 음량과는 별개로 곱해진다.

파일을 넣거나 바꾼 뒤에는 Godot 에디터를 한 번 열어(또는 --import) 임포트해야 게임이 인식한다.
